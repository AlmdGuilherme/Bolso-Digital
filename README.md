# Bolso Digital 
O Bolso Digital é um aplicativo de gestão financeira pessoal desenvolvido com React Native (Expo) no frontend e Node.js/Fastify + PostgreSQL no backend. O sistema permite que os usuários controlem suas finanças de forma prática através de contas digitais, categorização de gastos, metas financeiras e acompanhamento de investimentos. Entre suas principais funcionalidades estão a criação de envelopes financeiros, controle de despesas e receitas, definição de metas de economia, consulta de cotações de moedas e criptomoedas, além de gráficos e relatórios para análise financeira. O aplicativo também conta com autenticação segura, validação por SMS, suporte a tema claro e escuro e recursos de automação para gerenciamento de orçamento. O objetivo do projeto é fornecer uma experiência intuitiva que incentive a organização financeira e o planejamento de longo prazo.
